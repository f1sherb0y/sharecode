Welcome to ShareCode

For Apple silicon and Intel Macs. No Terminal commands needed.

① Open the DMG → ② Drag to Applications → ③ Open ShareCode → ④ Enable shortcuts
  1. Open the downloaded ShareCode Client.dmg.
  2. Drag ShareCode Client onto the Applications shortcut inside the disk window. Wait for copying to finish.
  3. In Finder, open Applications → ShareCode Client. Open the installed copy, not the one inside the disk image.
  4. If macOS says Apple cannot verify the app, dismiss that message. Open Apple menu → System Settings → Privacy & Security, scroll to the security section, and click Open Anyway next to ShareCode Client. Confirm and authenticate if asked.
  5. Paste your invitation link or code into ShareCode. You can now eject the ShareCode disk in Finder.

This build is not notarized by Apple. Only approve the copy you downloaded from your trusted ShareCode provider. A company-managed Mac may require your IT administrator to approve it. If macOS reports malware or a damaged app, ask your provider for help instead of following the approval steps above.

Enable keyboard shortcuts

  1. On the first launch without permission, ShareCode opens Input Monitoring and a setup window automatically. To reopen them later, click the ghost icon → Window settings → Input Monitoring settings.
  2. Drag the app icon from the setup window into the list in System Settings → Privacy & Security → Input Monitoring, then enable its switch. If already listed, just enable it. If dragging is unavailable, click + and choose Applications → ShareCode Client. Approve the change if macOS asks. On macOS 12 or earlier, the path is System Preferences → Security & Privacy → Privacy → Input Monitoring.
  3. If macOS asks you to quit and reopen, follow that prompt, then open ShareCode Client from Applications again. Closing its window alone does not quit the app.
  4. In the setup window or Window settings, once the listener is active, click Test shortcut and press Control + Shift + F within 15 seconds. A received-shortcut message confirms the test; this test does not toggle click-through.

Control + Shift + F toggles click-through. Control + Shift + Q quits the app. Use Control (⌃), not Command (⌘); either left or right Ctrl/Shift works. If the test times out, check the permission for the installed copy and restart the app before trying again.

Input Monitoring lets the native listener receive these shortcuts while another app is active. ShareCode does not record ordinary keystrokes or typed text. Click-through stays unavailable until the listener is ready.

The app starts without a Dock icon. To show it, open Window settings and turn off “Hide from Dock”. To restore a minimized window, open the installed app again.

安装 ShareCode

支持 Apple 芯片和 Intel Mac，无需输入终端命令。

① 打开 DMG → ② 拖入应用程序 → ③ 打开 ShareCode → ④ 开启快捷键
  1. 打开下载的 ShareCode Client.dmg。
  2. 将 ShareCode Client 拖到磁盘窗口中的 Applications（应用程序） 快捷方式上，等待复制完成。
  3. 在访达中打开 应用程序 → ShareCode Client。请打开已安装的副本，而不是磁盘镜像里的副本。
  4. 如果系统提示 Apple 无法验证此应用，请先关闭提示，然后打开 苹果菜单 → 系统设置 → 隐私与安全性，向下找到 ShareCode Client，点击 仍要打开。按提示确认并验证身份。
  5. 在 ShareCode 中粘贴邀请链接或邀请码即可。安装后可以在访达中推出 ShareCode 磁盘。

此版本未经 Apple 公证。请仅批准来自可信 ShareCode 提供方的应用。公司管理的 Mac 可能需要 IT 管理员批准。如果系统提示恶意软件或应用已损坏，请联系提供方，不要按上述步骤放行。

开启键盘快捷键

  1. 首次启动且尚未授权时，应用会自动打开输入监控页面和授权引导窗口。以后可从标题栏的幽灵图标（窗影）→ 输入监控设置再次打开。
  2. 将引导窗口中的应用图标拖进系统设置 → 隐私与安全性 → 输入监控的列表，再打开应用旁的开关。已在列表中时直接开启即可；无法拖入时可点 +，选择应用程序 → ShareCode Client，按系统提示验证身份。macOS 12 及更早版本的路径为系统偏好设置 → 安全性与隐私 → 隐私 → 输入监控。
  3. 如果系统提示退出并重新打开，请按提示操作，然后从应用程序重新打开 ShareCode Client。只关闭窗口不等于退出应用。
  4. 在引导窗口或窗影中，等待显示原生快捷键监听已启用，点击测试快捷键，在 15 秒内按 Control + Shift + F。看到“已收到快捷键”即测试成功；这次测试不会切换穿透。

Control + Shift + F 切换穿透，Control + Shift + Q 退出应用。使用 Control（⌃），不是 Command（⌘）；左右 Ctrl/Shift 均可。测试超时时，请确认开启的是已安装应用的权限，重启应用后重试。

输入监控用于在其他应用位于前台时接收这些快捷键。ShareCode 不记录普通按键或输入文字。监听就绪后才能开启穿透。

应用默认不显示程序坞图标。在窗影中关闭“程序坞隐藏”即可显示。恢复最小化窗口时，请重新打开已安装的应用。
