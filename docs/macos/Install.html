Install ShareCode

Open the DMG, drag ShareCode Client to Applications, then open the installed copy.

  1. If macOS blocks the first launch, open System Settings → Privacy & Security and choose Open Anyway.
  2. Follow the in-app guide: drag the app into Input Monitoring, enable it, then do the same for Screen Recording.
  3. Reopen the app if macOS asks. The main window appears after both permissions are ready.

This local build is ad-hoc signed and is not notarized by Apple. Use only the app from your trusted ShareCode source.

Ctrl + Shift + F toggles click-through. Ctrl + Shift + Q quits.

安装 ShareCode

打开 DMG，把 ShareCode Client 拖到 应用程序，再打开已安装的副本。

  1. 如果 macOS 拦截首次启动，打开系统设置 → 隐私与安全性，点击仍要打开。
  2. 按应用内引导操作：把 App 拖入输入监控并开启，再对屏幕录制重复一次。
  3. 按系统提示重新打开应用。两项权限就绪后才会显示主窗口。

此本地版本使用临时签名，未经 Apple 公证。请只使用可信 ShareCode 来源提供的应用。

Ctrl + Shift + F 切换穿透，Ctrl + Shift + Q 退出。
